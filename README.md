### 概要：
* AI関連APIを利用する絵描きアプリを作るために、まず基本的な描きアプリの機能を使用できるアプリ（saiやClip Studioのよう）を目指します。
* 液晶タブレットやペンタブレットを使用する前提として開発しました、今後Androidにも対応する予定です。
* 総作業時間はまだ1、2週間程度なので、開発自体はまだ初歩的な状態です（GeminiとGhatGptを利用してます）。
* 実行できるアプリはIllustrationBase.zipです、ZIPファイルを解凍して、中のIllustrationBase.exeをダブルクリックすると起動できます。
* 開発環境はUnity6000.3.14f1
### 現時点の機能説明：
* サイズ：ペンのサイズを調整。
* 不透明度：ペンの不透明度調整、調整範囲0.0～1.0。
* 硬さ：ペンの硬さを調整、調整範囲0.0～1.0。
* R：ペンの色のR値を調整、調整範囲0～255。
* G：ペンの色のR値を調整、調整範囲0～255。
* B：ペンの色のR値を調整、調整範囲0～255。
* 保存：このボタンを押すと、C:\Users\ユーザー名\AppData\LocalLow\DefaultCompany\IllustrationBaseの下にMySketch_XXXのPNG画像として保存されます。
* ブラシ：ブラシのアイコンのボタンを押すと、ブラシ入力に切り替えます。
* 消しゴム：：消しゴムのアイコンのボタンを押すと、消し込む入力に切り替えます。
* +：レイヤーを一枚新規追加
* レイヤー：該当レイヤーを見える/見えないに切り替えする。
### 問題点：
* マルチレイヤー（レイヤー分け）導入済みですが、機能はまだ作業中です
* 保存機能にまだ正しい画像を保存されてない問題が残ってます
